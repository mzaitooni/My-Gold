# ذهب هنادي

## رفع الصفحة على GitHub Pages

1. أنشئي مستودعًا جديدًا في GitHub أو افتحي المستودع الذي تريدين استخدامه.
2. ارفعي الملفين `index.html` و`README.md` إلى المستوى الرئيسي للمستودع.
3. افتحي **Settings → Pages**.
4. اختاري **Deploy from a branch**، ثم فرع `main` ومجلد `/ (root)`، واضغطي **Save**.
5. بعد اكتمال النشر، افتحي الرابط الذي يظهر في صفحة Pages.

تُحفظ بيانات الجرد على الجهاز والمتصفح. استخدمي النسخة الاحتياطية من إعدادات الصفحة واحفظيها في iCloud Drive لنقل القطع والصور وسعر الذهب إلى جهاز آخر.
